右上角「圖例」方框： 藍色實線箭頭 — 吸收 橘色波浪箭頭 — 振動躍遷（碰撞，不放光） 綠色實線箭頭 — 螢光（允許） 紫色虛線箭頭 — 磷光（禁止，延遲）

最下方一排粉彩公式盒（三個）：

  1. 淺藍盒：∫Ψ_f* r Ψ_i dτ = [∫ψ_f* r ψ_i dV]·⟨s_f|s_i⟩，說明「偶極算符碰不到自旋 → 自旋部分必須相同」

  2. 淺紫盒：ΔS = 0，說明「單重態與三重態互相正交 → 之間的輻射躍遷被禁止」
