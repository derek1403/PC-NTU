## Q1. p 值與後驗機率

程式：[sol_q1.py](sol_q1.py)

**(a)** 標準化 $z = (1.0 - 0)/0.5 = 2$：

$$p = \Pr(\hat d \ge 1.0 \mid d = 0) = 1 - \Phi(2) = \Phi(-2) \approx 0.0228$$

（雙尾為 $0.0455$）程式：`1 - stats.norm.cdf(2)` 或 `stats.norm.sf(2)`。

**(b)** 平坦先驗下後驗正比於概似函數：$d \mid \hat d \sim \mathcal N(1.0,\ 0.5^2)$。

$$\Pr(d > 0 \mid \hat d = 1.0) = \Pr\left(Z > \frac{0 - 1.0}{0.5}\right) = \Phi(2) \approx 0.9772$$

**(c)** 和 hw3 Q2 的卡爾曼增益完全相同（先驗 = 背景、$\hat d$ = 觀測）：

$$\begin{gather*}
K &=& \frac{\sigma_0^2}{\sigma_0^2 + \sigma^2} = \frac{0.25}{0.25 + 0.25} = 0.5 \\
\mu_{\text{post}} &=& \mu_0 + K(\hat d - \mu_0) = -0.5 + 0.5 \times 1.5 = 0.25 \\
\sigma_{\text{post}} &=& \sqrt{(1 - K)\sigma_0^2} = \sqrt{0.125} \approx 0.3536 \\
\Pr(d > 0 \mid \hat d) &=& \Phi\left(\frac{0.25}{0.3536}\right) = \Phi(0.707) \approx 0.7602
\end{gather*}$$

* 後驗機率從 $0.977$ 降到 $0.760$：先驗偏向負值，把後驗中心往負的方向拉。
* p 值**不會**改變，仍是 $0.0228$：p 值 $= \Pr(\text{資料} \mid H_0)$ 只用到 $H_0$ 下資料的抽樣分布，公式裡沒有先驗。

## Q2. 迴歸斜率的 Bootstrap 信賴區間

程式：[sol_q2.py](sol_q2.py)

| 項目 | 數值 |
| ---- | ---- |
| $\hat a$ | $1.0192$ |
| $\hat b$ | $0.7617$ |
| $\mathrm{SE}_{\mathrm{OLS}}(\hat b)$ | $0.2468$ |
| $t_{0.975,\,48}$ | $2.0106$ |
| OLS 95% CI | $[0.2655,\ 1.2579]$ |
| bootstrap 斜率標準差 | $0.2217$ |
| bootstrap 95% CI | $[0.3374,\ 1.1954]$ |

**(c)** 兩個區間相近，bootstrap 稍窄（$n = 50$ 較小，bootstrap 沒有 $n-2$ 與 $t$ 分布的小樣本修正，也有有限 $B$ 的誤差）。兩個區間都**不包含 0**，所以在 5% 水準下拒絕 $H_0: b = 0$。

**(d)** 不行。pairs bootstrap 保留了 $x$、$y$ 的配對關係，分布中心在 $\hat b \approx 0.76$，描述的是 $\hat b$ 的**抽樣不確定性**（用來做信賴區間）。虛無分布必須假設 $H_0$ 成立，中心在 0（用來算 p 值），建構時要強制 $b = 0$，例如打亂配對（permutation）、從 $H_0$ 模型產生資料，或把 bootstrap 分布平移 $\hat b^* - \hat b$。

| $\phi$ | 誤拒絕率 | $\hat b$ 的真實標準差 | $\mathrm{SE}_{\mathrm{OLS}}$ 平均 | 比值 |

## Q4.（加分題）用 AR(2) 表示正弦波

程式：[sol_q4.py](sol_q4.py)

**(a)** 由 $\sin(\omega t + \omega) + \sin(\omega t - \omega) = 2\cos\omega \sin(\omega t)$，得

$$z_t = 2\cos\omega\, z_{t-1} - z_{t-2}, \qquad \omega = \frac{2\pi}{12} \Rightarrow \phi_1 = 2\cos\frac{\pi}{6} = \sqrt3 \approx 1.7321, \quad \phi_2 = -1, \quad c = 0$$

OLS 結果：$c = 0.0000$，$\phi_1 = 1.7321$，$\phi_2 = -1.0000$，與理論值完全相同。

**(b)** 20 步遞迴預報 RMSE $\approx 1.5 \times 10^{-14}$（只剩浮點數捨入誤差），因為無雜訊的正弦波恰好滿足這個二階遞迴。
