# Division Algorithm for Polynomials (多項式的除法原理)

+++

## 證明目標:

`FiniteFields.pdf` p.7–p.8；補充講義 §7.5.2（Exercise 7）。
「多項式長除法」是整個有限體算術的發動機 —— $GF(2^8)$ 裡每一次乘法後面都跟著一次除法取餘。
[模不可約多項式的商環是體](../../Abstract_Algebra/Field/Quotient_by_Irreducible_is_Field.md)【已知 2(c)】
當時是**引用未證**的，本檔把它完整證出。

* (a) 存在性（投影片 p.7 的 Theorem）：

$$\forall\, a(x), b(x) \in F[x],\ b \neq 0, \ \exists\, q(x), r(x) \in F[x] \ \text{ with } \ a = bq + r, \quad r = 0 \ \text{或} \ \deg r < \deg b$$

* (b) 唯一性（補充講義 Exercise 7(b)，投影片未列）：上式的 $q, r$ 唯一。

* (c) 投影片 p.8 的例子（在 $GF(11)[x]$ 中）：

$$3x^4 + 5x + 2 = \left(2x^3 + x^2 + 5\right)\left(7x + 2\right) + \left(9x^2 + 3x + 3\right)$$

* (d) 模 $m(x)$ 的同餘類與「次數 $< \deg m$ 的餘式」一一對應，共 $\left|F\right|^{\deg m}$ 個（補充講義 §7.5.2）：

$$a \equiv b \pmod{m} \ \Longleftrightarrow \ a \bmod m = b \bmod m, \qquad \left|F[x]/\left\langle m \right\rangle\right| = \left|F\right|^{\deg m}$$

* $F$ : 係數所在的體 (The field of coefficients) $[\text{體}]$
* $a(x)$ : 被除式 (The dividend) $[a \in F[x]]$
* $b(x)$ : 除式 (The divisor) $[b \in F[x] \setminus \left\{0\right\}]$
* $q(x)$ : 商式 (The quotient) $[q \in F[x]]$
* $r(x)$ : 餘式 (The remainder) $[r \in F[x]]$
* $m(x)$ : 模多項式 (The modulus) $[m \in F[x],\ \deg m \ge 1]$
* 註：**投影片 p.7 的定理漏了 $b(x) \neq 0$**。$b = 0$ 時 $\deg r < \deg b = -\infty$ 不可能成立，
  而 $r = 0$ 又迫使 $a = 0$，所以對 $a \neq 0$ 無解。本檔補上此條件。
* 註：投影片 p.7 的證明是 Sketch（「Continue until …」）；本檔以**強歸納法**寫成完整證明（【證明 (a)】）。

## 假設與已知 (Assumptions & Preliminaries)

* **【已知 1】 [體上多項式的次數相加 (Degrees add over a field)](https://derek1403.github.io/PC-NTU/Cryptography/_build/html/lecture/Algebra/Finite_Fields/Polynomial_Arithmetic/Polynomial_Ring_over_a_Field.html#b-proof-that-degrees-add-in-the-polynomial-ring-over-a-field)：** 已於本章 [體上的多項式環](Polynomial_Ring_over_a_Field.md)【定義 1】【推導 1】【證明 (b)】給出並證明，此處直接引用不再重證

  * (a) 次數相加（含 $\deg 0 = -\infty$ 的約定）：

    $$\deg\left(fg\right) = \deg f + \deg g$$

  * (b) 首項相乘：

    $$\mathrm{LT}\!\left(fg\right) = \mathrm{LT}(f)\,\mathrm{LT}(g) \qquad \left(f, g \neq 0\right)$$

  * (c) 次數由係數決定：兩個多項式相減，次數不超過兩者的較大者；若兩者次數同為 $N$ 且首項相同，差的次數 $< N$：

    $$\deg\left(f - g\right) \le \max\left(\deg f,\ \deg g\right), \qquad \mathrm{LT}(f) = \mathrm{LT}(g) \Longrightarrow \deg\left(f - g\right) < \deg f$$

  * $f,\ g$ : 多項式 (Polynomials) $[f, g \in F[x]]$
  * $\mathrm{LT}$ : 首項 (Leading term) $[F[x] \setminus \left\{0\right\} \to F[x]]$

* **【已知 2】 [體的非零元素可逆 (Non-zero elements of a field are invertible)](https://derek1403.github.io/PC-NTU/Cryptography/_build/html/lecture/Algebra/Abstract_Algebra/Field/Field_Definition.html#assumptions-preliminaries)：** 已於 [體的定義](../../Abstract_Algebra/Field/Field_Definition.md)【定義 1】給出，此處直接引用

  $$c \in F \setminus \left\{0\right\} \quad \Longrightarrow \quad \exists\, c^{-1} \in F$$

  * $c$ : 非零體元素 (A non-zero field element) $[c \in F]$

* **【已知 3】 [強歸納法 (Strong induction)](https://mathworld.wolfram.com/PrincipleofStrongInduction.html)：** 良序原理的等價形式，標準結果，直接引用不再重證

  $$\left[\,\forall N:\ \left(P(k) \ \forall k < N\right) \Longrightarrow P(N)\,\right] \quad \Longrightarrow \quad P(N) \ \forall N \in \mathbf{N}$$

  * $P$ : 待證命題 (The statement to be proved) $[\mathbf{N} \to \left\{\text{真},\text{假}\right\}]$
  * $N,\ k$ : 自然數 (Natural numbers) $[N, k \in \mathbf{N}]$

* **【已知 4】 [模理想的同餘 (Congruence modulo an ideal)](https://derek1403.github.io/PC-NTU/Cryptography/_build/html/lecture/Algebra/Abstract_Algebra/Ring/Congruence_Class_Modulo_Ideal.html#a-proof-that-congruence-modulo-an-ideal-is-an-equivalence-relation)：** 已於 [模理想的同餘類](../../Abstract_Algebra/Ring/Congruence_Class_Modulo_Ideal.md)【證明 (a)】完整證明，此處直接引用不再重證。投影片 p.8 的定義就是取理想 $I = \left\langle m(x) \right\rangle$ 的特例

  $$a \equiv b \pmod{m} \quad \overset{\text{def}}{\Longleftrightarrow} \quad a - b \in \left\langle m \right\rangle \quad \Longleftrightarrow \quad m \mid \left(a - b\right)$$

  * $\left\langle m \right\rangle$ : $m$ 生成的主理想 (The principal ideal generated by $m$) $[\left\langle m \right\rangle \trianglelefteq F[x]]$
  * 註：此關係是等價關係，同餘類就是商環 $F[x]/\left\langle m \right\rangle$ 的元素。

* **【定義 1】 餘式記號 (Remainder notation)：** 投影片 p.8

  $$a \bmod b \overset{\text{def}}{=} r \qquad \text{（【證明 (a)(b)】給出的唯一餘式）}$$

  * $a \bmod b$ : $a$ 除以 $b$ 的餘式 (The remainder of $a$ on division by $b$) $[F[x]]$
  * 註：此記號的良定義性正是【證明 (b)】的唯一性。

* **【假設 1】 歸納假設 (Induction hypothesis)：** 【證明 (a)】對 $\deg a$ 做強歸納時的假設。
  固定 $b$（$\deg b = m$），設 $N \ge m$，且次數 $< N$ 的被除式都能除

  $$\deg a' < N \quad \Longrightarrow \quad \exists\, q', r' \ \text{ with } \ a' = bq' + r', \quad r' = 0 \ \text{或} \ \deg r' < m$$

  * $a'$ : 次數較低的被除式 (A dividend of lower degree) $[a' \in F[x]]$
  * $q',\ r'$ : 其商與餘式 (Its quotient and remainder) $[q', r' \in F[x]]$
  * $N$ : 當前歸納的次數 (The current degree) $[N \in \mathbf{N}]$

* **【假設 2】 兩組商與餘式 (Two quotient-remainder pairs)：** 【證明 (b)】的出發點

  $$a = bq_1 + r_1 = bq_2 + r_2, \qquad \deg r_i < \deg b \ \text{或} \ r_i = 0$$

  * $q_1,\ q_2$ : 兩個商式 (Two quotients) $[q_i \in F[x]]$
  * $r_1,\ r_2$ : 兩個餘式 (Two remainders) $[r_i \in F[x]]$

* **【推導 1】 消去首項 (Cancelling the leading term)：** 投影片 p.7 的 $q_1(x) = \mathrm{LT}(a)/\mathrm{LT}(b)$。
  設 $\mathrm{LT}(a) = a_N x^N$、$\mathrm{LT}(b) = b_m x^m$、$N \ge m$

  $$\begin{gather*}
  q_1 &\overset{\text{let}}{=}& a_N\, b_m^{-1}\, x^{N-m} \\
  b_m^{-1} &\overset{\text{已知 2}}{\in}& F \\
  \mathrm{LT}\!\left(b\,q_1\right) &\overset{\text{已知 1(b)}}{=}& b_m x^m \cdot a_N b_m^{-1} x^{N-m} \\
  \mathrm{LT}\!\left(b\,q_1\right) &=& a_N x^N \\
  \mathrm{LT}\!\left(b\,q_1\right) &=& \mathrm{LT}(a) \\
  \deg\left(a - bq_1\right) &\overset{\text{已知 1(c)}}{<}& N
  \end{gather*}$$

  * $q_1$ : 第一個部分商 (The first partial quotient) $[q_1 \in F[x]]$
  * $a_N,\ b_m$ : 首項係數 (Leading coefficients) $[a_N, b_m \in F \setminus \left\{0\right\}]$
  * $N,\ m$ : $a, b$ 的次數 (The degrees of $a, b$) $[N, m \in \mathbf{N}]$
  * 註：**這是唯一需要「$F$ 是體」的地方** —— $b_m^{-1}$ 必須存在。
    在 $\mathbf{Z}[x]$ 中 $x^2 \div 2x$ 就卡住了（$1/2 \notin \mathbf{Z}$），
    見 [$\mathbf{Z}[x]$ 中的非主理想](../../Abstract_Algebra/Ring/Non_Principal_Ideal_in_Z_x.md)。
  * 註：若 $b$ 是首一的（$b_m = 1$），則不必求逆，除法對任意交換含單位元環都成立。

## 證明:

### (a) proof of the existence of the quotient and remainder

**基底情形**：$a = 0$ 或 $\deg a < \deg b = m$。取 $q = 0$、$r = a$：

$$\begin{gather*}
a &=& b \cdot 0 + a \\
\deg r = \deg a &<& m \qquad \text{(或 } r = a = 0\text{)}
\end{gather*}$$

**歸納步驟**：設 $\deg a = N \ge m$，且【假設 1】成立。先用【推導 1】削掉首項，再對剩下的低次式套歸納假設：

$$\begin{gather*}
a_1 &\overset{\text{let}}{=}& a - b\,q_1 \\
\deg a_1 &\overset{\text{推導 1}}{<}& N \\
a_1 &\overset{\text{假設 1}}{=}& b\,q' + r' \qquad \text{with } r' = 0 \ \text{或} \ \deg r' < m \\
a &=& b\,q_1 + a_1 \\
a &=& b\,q_1 + b\,q' + r' \\
a &=& b\left(q_1 + q'\right) + r'
\end{gather*}$$

取 $q = q_1 + q'$、$r = r'$ 即得。基底與歸納步驟合起來：

$$\text{存在性對所有 } \deg a \in \mathbf{N} \ \text{成立} \quad \overset{\text{已知 3}}{\Longleftarrow} \quad \text{基底情形} + \text{歸納步驟}$$

* 註：投影片寫的「Continue until $a_k(x) = 0$ or $\deg\left(a_k(x)\right) < \deg\left(b(x)\right)$，
  Then $r = a_k$、$q = q_1 + \cdots + q_k$」就是把本證明的歸納**展開成迴圈** ——
  每一圈削掉一個首項，次數嚴格下降，所以迴圈必定停止。

### (b) proof of the uniqueness of the quotient and remainder

由【假設 2】兩式相減：

$$\begin{gather*}
b\left(q_1 - q_2\right) &=& r_2 - r_1 \\
\deg\left(r_2 - r_1\right) &\overset{\text{已知 1(c),假設 2}}{<}& \deg b
\end{gather*}$$

若 $q_1 \neq q_2$，左邊的次數至少是 $\deg b$：

$$\begin{gather*}
\deg\left[b\left(q_1 - q_2\right)\right] &\overset{\text{已知 1(a)}}{=}& \deg b + \deg\left(q_1 - q_2\right) \\
\deg\left[b\left(q_1 - q_2\right)\right] &\ge& \deg b + 0
\end{gather*}$$

與上一段「$< \deg b$」矛盾。故 $q_1 = q_2$，代回得 $r_2 - r_1 = b \cdot 0 = 0$：

$$q_1 = q_2, \qquad r_1 = r_2$$

故【定義 1】的 $a \bmod b$ 良定義。

### (c) verify the division example over the field with eleven elements

$a = 3x^4 + 5x + 2$、$b = 2x^3 + x^2 + 5$。在 $GF(11)$ 中 $2^{-1} = 6$（$2 \cdot 6 = 12 \equiv 1$）。
**第一圈**（【推導 1】）：

$$\begin{gather*}
q_1 &\overset{\text{推導 1}}{=}& 3 \cdot 6\, x = 18x \equiv 7x \\
b\,q_1 &=& 14x^4 + 7x^3 + 35x \equiv 3x^4 + 7x^3 + 2x \\
a_1 = a - b\,q_1 &=& -7x^3 + 3x + 2 \equiv 4x^3 + 3x + 2
\end{gather*}$$

**第二圈**：

$$\begin{gather*}
q_2 &\overset{\text{推導 1}}{=}& 4 \cdot 6 = 24 \equiv 2 \\
b\,q_2 &=& 4x^3 + 2x^2 + 10 \\
a_2 = a_1 - b\,q_2 &=& -2x^2 + 3x - 8 \equiv 9x^2 + 3x + 3
\end{gather*}$$

$\deg a_2 = 2 < 3 = \deg b$，停止。故

$$\begin{gather*}
q &\overset{\text{證明 (a)}}{=}& q_1 + q_2 = 7x + 2 \\
r &\overset{\text{證明 (a)}}{=}& 9x^2 + 3x + 3 \\
a \bmod b &\overset{\text{定義 1}}{=}& 9x^2 + 3x + 3
\end{gather*}$$

與投影片 p.8 一致；投影片寫的 $a(x) \equiv 9x^2 + 3x + 3 \pmod{b(x)}$ 由【已知 4】即 $b \mid \left(a - r\right) = bq$。

### (d) proof that the residues modulo a polynomial are counted by the remainders

設 $\deg m = n \ge 1$。**同餘等價於同餘式**：由【證明 (a)】寫 $a = mq_a + r_a$、$b = mq_b + r_b$：

$$\begin{gather*}
a - b &=& m\left(q_a - q_b\right) + \left(r_a - r_b\right) \\
a \equiv b \pmod{m} &\overset{\text{已知 4}}{\Longleftrightarrow}& m \mid \left(r_a - r_b\right) \\
m \mid \left(r_a - r_b\right) &\overset{\text{證明 (b)}}{\Longleftrightarrow}& r_a - r_b = 0 \qquad \text{(次數 } < n \text{ 又被 } m \text{ 整除，只能是 } 0\text{)} \\
a \equiv b \pmod{m} &\overset{\text{定義 1}}{\Longleftrightarrow}& a \bmod m = b \bmod m
\end{gather*}$$

**計數**：每個同餘類恰對應一個次數 $< n$ 的餘式 $r_0 + r_1 x + \cdots + r_{n-1}x^{n-1}$，
$n$ 個係數各有 $\left|F\right|$ 種選擇：

$$\left|F[x]\big/\left\langle m \right\rangle\right| = \left|F\right|^{n} = \left|F\right|^{\deg m}$$

* 註：第三行的「$\Leftarrow$」顯然；「$\Rightarrow$」是把 $r_a - r_b = m \cdot k + 0$ 與 $r_a - r_b = m \cdot 0 + \left(r_a - r_b\right)$
  兩種寫法交給【證明 (b)】的唯一性比較。
* 註：取 $F = GF(2)$、$\deg m = 8$，得 $2^8 = 256$ 個同餘類 —— **一個位元組**。

## 意義與密碼學關聯 (Interpretation and Relevance to Cryptography)

### 「取模」就是「除完留餘」

$\mathbf{Z}$ 與 $F[x]$ 的對照：

| 整數 | 多項式 |
|---|---|
| $a = bq + r$，$0 \le r < \left|b\right|$ | $a = bq + r$，$\deg r < \deg b$ |
| 大小用 $\left|\cdot\right|$ 量 | 大小用 $\deg$ 量 |
| $a \bmod n \in \left\{0, \dots, n-1\right\}$ | $a \bmod m \in \left\{\text{次數} < \deg m\right\}$ |
| $\left|\mathbf{Z}_n\right| = n$ | $\left|F[x]/\left\langle m \right\rangle\right| = \left|F\right|^{\deg m}$ |

這個平行性在 [歐幾里得整環](Euclidean_Domain.md) 被抽象成一個定義。

### AES 的 xtime：除法原理的一行實作

在 $GF(2)[x]$ 中除以 $m(x) = x^8 + x^4 + x^3 + x + 1$ 時，
若被除式次數恰為 $8$，【推導 1】只需做**一圈**：$q_1 = 1$、$a - m$。
在位元層次就是「若第 8 位元為 1，就 XOR 上 $\texttt{0x11B}$」：

```python
def reduce_once(a):
    """次數 <= 8 的 GF(2)[x] 元素對 0x11B 取餘：證明 (a) 只跑一圈。"""
    return a ^ 0x11B if a & 0x100 else a
```

這就是 [AES 的 $GF(2^8)$ 算術](../AES/AES_GF_2_8_Arithmetic.md) 裡 `xtime` 的核心。
**常數時間**（不依賴資料的分支）的實作會改寫成 `a ^ (0x11B & -(a >> 8))`，避免側通道洩漏。

### 程式思維

```python
def poly_divmod(a, b, p):
    """F_p[x] 長除法，係數由低到高。回傳 (q, r)。每一圈就是推導 1。"""
    a, q = a[:], [0] * max(0, len(a) - len(b) + 1)
    inv = pow(b[-1], p - 2, p)            # 已知 2：首項係數可逆
    while len(a) >= len(b) and any(a):
        c, d = a[-1] * inv % p, len(a) - len(b)
        q[d] = c
        for i, y in enumerate(b):
            a[i + d] = (a[i + d] - c * y) % p
        while a and a[-1] == 0:
            a.pop()
    return q, a

assert poly_divmod([2, 5, 0, 0, 3], [5, 0, 1, 2], 11) == ([2, 7], [3, 3, 9])   # 證明 (c)
```
