# Principal Ideal (主理想)

+++

## 證明目標:

`Algebra.pdf` p.33（下半）與 p.36。由**單一個元素**生成的理想 ——
與 [循環群](../Group/Cyclic_Group.md) 是同一種「結構最單純」的想法。

* (a) $\langle 1 \rangle = R$。
* (b) $\langle x \rangle$ 與 $\left\langle x^2 + 1 \right\rangle$ 是 $\mathbf{Z}[x]$ 的主理想。
* (c) **$\mathbf{Z}$ 的每個理想都是主理想**（即 $\mathbf{Z}$ 是 PID）：

$$I \trianglelefteq \mathbf{Z} \quad \Longrightarrow \quad I = \langle d \rangle \ \text{ for some } d \in \mathbf{N}$$

* (d) $\langle 15, 21 \rangle = \langle 3 \rangle$。
* (e) $\langle x, y \rangle$ 在 $\mathbf{Q}[x, y]$ 中**不是**主理想。

* $R$ : 環的底層集合 (The underlying set of the ring) $[\text{集合}]$
* $I$ : $R$ 的理想 (An ideal of $R$) $[I \trianglelefteq R]$
* $a,\ d$ : 生成元 (Generators) $[a, d \in R]$
* $\langle a \rangle$ : 由 $a$ 生成的主理想 (The principal ideal generated by $a$) $[\langle a \rangle \trianglelefteq R]$
* $\mathbf{Z}[x],\ \mathbf{Q}[x,y]$ : 多項式環 (Polynomial rings) $[\text{集合}]$
* 註：(e) 說明**不是每個理想都是主理想**。另一個反例（$\mathbf{Z}[x]$ 中常數項為偶數的理想）
  因為證明較長，另立一檔：[$\mathbf{Z}[x]$ 中的非主理想](Non_Principal_Ideal_in_Z_x.md)。
* 註：(c) 的證明是**帶餘除法 + 良序原理**的標準組合，
  與 [元素的階與循環子群](../Group/Order_of_Element_and_Cyclic_Subgroup.md)【推導 1】【推導 2】
  用的是同一套工具 —— 「取最小的那個，用除法把別人都打回去」。
* 註：主理想與循環子群是同一個想法在兩個結構上的版本：
  $\langle a \rangle = aR$ 對應 $\langle g \rangle = \left\{g^n\right\}$。

## 假設與已知 (Assumptions & Preliminaries)

* **【已知 1】 [理想的定義與判別法 (Definition and criterion for ideals)](https://derek1403.github.io/PC-NTU/Cryptography/_build/html/lecture/Algebra/Abstract_Algebra/Ring/Ideal.html#b-proof-that-the-set-of-multiples-of-an-element-is-an-ideal)：** 已於本章 [理想](Ideal.md)【定義 1】【推導 1】【證明 (b)】給出並證明，此處直接引用不再重證

  * (a) 理想的兩條性質：

    $$\left(I, +\right) \le \left(R, +\right), \qquad ar \in I \ \text{ for all } a \in I,\ r \in R$$

  * (b) $aR$ 恆為理想：

    $$aR = \left\{ar \ \middle|\ r \in R\right\} \trianglelefteq R$$

  * $I$ : $R$ 的理想 (An ideal of $R$) $[I \trianglelefteq R]$
  * $R$ : 環的底層集合 (The underlying set of the ring) $[\text{集合}]$
  * $a$ : 理想中的元素 (An element of the ideal) $[a \in I]$
  * $r$ : 母環中的元素 (An element of the ambient ring) $[r \in R]$

* **【已知 2】 [良序原理與除法原理 (Well-ordering principle and the division algorithm)](https://derek1403.github.io/PC-NTU/Cryptography/_build/html/lecture/Algebra/Abstract_Algebra/Group/Order_of_Element_and_Cyclic_Subgroup.html#assumptions-preliminaries)：** 已於本章 [元素的階與循環子群](../Group/Order_of_Element_and_Cyclic_Subgroup.md)【已知 6】引用，此處再次引用

  * (a) 良序原理：

    $$S \subseteq \mathbf{P},\ S \neq \varnothing \quad \Longrightarrow \quad S \ \text{有最小元素}$$

  * (b) 除法原理：

    $$\forall\, m \in \mathbf{Z},\ d \in \mathbf{P}, \ \exists\, q, r \in \mathbf{Z} \ \text{ such that } \ m = qd + r,\ 0 \le r < d$$

  * $S$ : 正整數的非空子集 (A non-empty subset of the positive integers) $[S \subseteq \mathbf{P}]$
  * $m$ : 被除數 (The dividend) $[m \in \mathbf{Z}]$
  * $d$ : 除數 (The divisor) $[d \in \mathbf{P}]$
  * $q,\ r$ : 商與餘數 (The quotient and the remainder) $[q, r \in \mathbf{Z}]$

* **【已知 3】 [貝祖等式 (Bézout's identity)](https://derek1403.github.io/PC-NTU/Cryptography/_build/html/lecture/Algebra/Abstract_Algebra/Ring/Ideal.html#assumptions-preliminaries)：** 已於本章 [理想](Ideal.md)【已知 5(b)】引用，此處再次引用

  $$m\mathbf{Z} + n\mathbf{Z} = \gcd(m, n)\,\mathbf{Z}$$

  * $m,\ n$ : 兩個正整數 (Two positive integers) $[m, n \in \mathbf{P}]$
  * $\gcd$ : 最大公因數 (Greatest common divisor) $[\mathbf{P} \times \mathbf{P} \to \mathbf{P}]$

* **【已知 4】 [多項式環與整環的次數性質 (Polynomial rings and degree in an integral domain)](https://derek1403.github.io/PC-NTU/Cryptography/_build/html/lecture/Algebra/Abstract_Algebra/Ring/Integral_Domain.html#assumptions-preliminaries)：** 已於本章 [整環](Integral_Domain.md)【推導 2】完整證明，此處直接引用不再重證

  * (a) 次數可加（$R$ 為整環時）：

    $$\deg\left(fg\right) = \deg f + \deg g$$

  * (b) 多變元遞迴構造：

    $$R[x, y] = \left(R[x]\right)[y]$$

  * $f,\ g$ : 非零多項式 (Non-zero polynomials) $[f, g \in R[x]]$
  * $R$ : 係數所在的整環 (The coefficient integral domain) $[\text{環}]$
  * $\deg$ : 多項式的次數 (The degree of a polynomial) $[R[x] \setminus \left\{0\right\} \to \mathbf{N}]$
  * $x,\ y$ : 未定元 (Indeterminates) $[x, y \notin R]$
  * 註：在 $\mathbf{Q}[x,y]$ 中，$\deg$ 指的是**總次數**（$x$ 與 $y$ 的次數之和）。
    (a) 對總次數同樣成立，因為 $\mathbf{Q}[x,y]$ 是整環（[整環](Integral_Domain.md)【證明 (b)】）。

* **【定義 1】 主理想與生成的理想 (Principal ideal and generated ideal)：**

  * (a) 主理想（由**一個**元素生成）：

    $$\langle a \rangle \overset{\text{def}}{=} aR = \left\{ar \ \middle|\ r \in R\right\}$$

  * (b) 由多個元素生成的理想：

    $$\left\langle a_1, \dots, a_k \right\rangle \overset{\text{def}}{=} \left\{a_1 r_1 + \dots + a_k r_k \ \middle|\ r_i \in R\right\}$$

  * $\langle a \rangle$ : 由 $a$ 生成的主理想 (The principal ideal generated by $a$) $[\langle a \rangle \trianglelefteq R]$
  * $a,\ a_i$ : 生成元 (Generators) $[a, a_i \in R]$
  * $r,\ r_i$ : 母環中的元素 (Elements of the ambient ring) $[r, r_i \in R]$
  * $R$ : 環的底層集合 (The underlying set of the ring) $[\text{集合}]$
  * $k$ : 生成元個數 (The number of generators) $[k \in \mathbf{P}]$
  * 註：(b) 是 (a) 的推廣，也可寫成 $\left\langle a_1 \right\rangle + \dots + \left\langle a_k \right\rangle$
    （[理想](Ideal.md)【定義 2(b)】的和）。它是理想，由 [理想](Ideal.md)【證明 (b)(e)】保證。
  * 註：投影片 p.36 的 $\left\langle 15, 21 \right\rangle := \left\{15m + 21n \ \middle|\ m, n \in \mathbf{Z}\right\}$
    就是 (b) 取 $k = 2$、$R = \mathbf{Z}$ 的情形。

* **【定義 2】 主理想整環 (Principal ideal domain, PID)：**

  $$R \ \text{為 PID} \quad \overset{\text{def}}{\Longleftrightarrow} \quad R \ \text{為整環且每個理想都是主理想}$$

  * $R$ : 環的底層集合 (The underlying set of the ring) $[\text{集合}]$
  * 註：投影片 p.36 寫「$\mathbf{Z}$ is a PID – Principal Ideal Domain」，即【證明 (c)】的結論
    加上 [整環](Integral_Domain.md)【證明 (a)】的 $\mathbf{Z}$ 是整環。

* **【假設 1】 反設：$\langle x, y \rangle$ 是主理想 (Proof by contradiction)：** 【證明 (e)】的出發點

  $$\left\langle x, y \right\rangle = \left\langle f \right\rangle \qquad \text{for some } f \in \mathbf{Q}[x, y]$$

  * $f$ : 假定的單一生成元 (The putative single generator) $[f \in \mathbf{Q}[x,y]]$
  * $x,\ y$ : 未定元 (Indeterminates) $[x, y \notin \mathbf{Q}]$

* **【推導 1】 生成的理想裡每個元素的常數項為零 (Every element of the generated ideal has zero constant term)：** 【證明 (e)】要用

  $$\begin{gather*}
  g &\overset{\text{定義 1(b)}}{\in}& \left\langle x, y \right\rangle \\
  g &\overset{\text{定義 1(b)}}{=}& x h_1 + y h_2 \qquad \text{for some } h_1, h_2 \in \mathbf{Q}[x,y] \\
  g(0, 0) &=& 0 \cdot h_1(0,0) + 0 \cdot h_2(0,0) \\
  g(0, 0) &=& 0
  \end{gather*}$$

  * $g$ : 理想中的一個元素 (An element of the ideal) $[g \in \left\langle x, y \right\rangle]$
  * $h_1,\ h_2$ : 係數多項式 (Coefficient polynomials) $[h_1, h_2 \in \mathbf{Q}[x,y]]$
  * $x,\ y$ : 未定元 (Indeterminates) $[x, y \notin \mathbf{Q}]$
  * 註：$g(0,0)$ 就是 $g$ 的常數項。**每一項都至少帶一個 $x$ 或一個 $y$**，
    代入 $x = y = 0$ 後全部消失。特別地 $1 \notin \left\langle x, y \right\rangle$。

## 證明:

### (a) proof that the ideal generated by one is the whole ring

$$\begin{gather*}
\langle 1 \rangle &\overset{\text{定義 1(a)}}{=}& \left\{1 \times r \ \middle|\ r \in R\right\} \\
&=& \left\{r \ \middle|\ r \in R\right\} \\
&=& R
\end{gather*}$$

與投影片一致。

* 註：反過來也對 —— 由 [理想](Ideal.md) 文末，**含 $1$ 的理想只有 $R$ 自己**。
  故 $\langle a \rangle = R$ 等價於 $a$ 可逆。

### (b) verify the two principal ideals in the integer polynomial ring

直接套【定義 1(a)】與【已知 1(b)】：

$$\begin{gather*}
\langle x \rangle &\overset{\text{定義 1(a)}}{=}& x\,\mathbf{Z}[x] = \left\{x\,h(x) \ \middle|\ h \in \mathbf{Z}[x]\right\} \\
\langle x \rangle &\overset{\text{已知 1(b)}}{\trianglelefteq}& \mathbf{Z}[x] \\
\left\langle x^2 + 1 \right\rangle &\overset{\text{定義 1(a)}}{=}& \left(x^2+1\right)\mathbf{Z}[x] \\
\left\langle x^2 + 1 \right\rangle &\overset{\text{已知 1(b)}}{\trianglelefteq}& \mathbf{Z}[x]
\end{gather*}$$

兩者都是主理想（依【定義 1(a)】，由單一元素生成），與投影片一致。

* 註：$\langle x \rangle$ 就是「常數項為 $0$ 的整係數多項式」全體 ——
  對照 [理想](Ideal.md)【定義 3】的「常數項為**偶數**」，兩者形狀相似但性質天差地別，
  見 [$\mathbf{Z}[x]$ 中的非主理想](Non_Principal_Ideal_in_Z_x.md)。

### (c) proof that every ideal of the integers is principal

設 $I \trianglelefteq \mathbf{Z}$。

**情形一：$I = \left\{0\right\}$。** 則 $I = \langle 0 \rangle$，是主理想。

**情形二：$I \neq \left\{0\right\}$。** 取出 $I$ 中最小的正元素。先說明這樣的元素存在 ——
$I$ 含某個 $a \neq 0$，而 $-a = a \times \left(-1\right) \in I$（吸收性），故 $I$ 必含正元素：

$$\begin{gather*}
\exists\, a \in I,\ a &\neq& 0 \\
-a = a \times \left(-1\right) &\overset{\text{已知 1(a)}}{\in}& I \\
I \cap \mathbf{P} &\neq& \varnothing \qquad \text{(} a \text{ 與 } -a \text{ 必有一個是正的)} \\
d &\overset{\text{已知 2(a)}}{=}& \min\left(I \cap \mathbf{P}\right) \ \text{存在}
\end{gather*}$$

**再證 $I = \langle d \rangle$，用雙向包含。**

($\supseteq$) 由吸收性直接得到：

$$\begin{gather*}
d &\in& I \\
d t &\overset{\text{已知 1(a)}}{\in}& I \qquad \text{for all } t \in \mathbf{Z} \\
\langle d \rangle &\overset{\text{定義 1(a)}}{\subseteq}& I
\end{gather*}$$

($\subseteq$) 任取 $m \in I$，用除法原理把它對 $d$ 除一次，再證餘數必為 $0$：

$$\begin{gather*}
m &\overset{\text{已知 2(b)}}{=}& qd + r \qquad \text{with } 0 \le r < d \\
r &=& m - qd \\
qd &\overset{\text{已知 1(a)}}{\in}& I \qquad \text{(吸收性)} \\
r = m - qd &\overset{\text{已知 1(a)}}{\in}& I \qquad \text{(加法子群對減法封閉)} \\
0 \le r &<& d
\end{gather*}$$

若 $r > 0$，則 $r$ 是 $I$ 中一個比 $d$ 更小的正元素，與 $d$ 的最小性矛盾。故 $r = 0$：

$$\begin{gather*}
r &=& 0 \\
m &=& qd \\
m &\overset{\text{定義 1(a)}}{\in}& \langle d \rangle \\
I &\subseteq& \langle d \rangle
\end{gather*}$$

兩個包含合起來得 $I = \langle d \rangle$。故 $\mathbf{Z}$ 的每個理想都是主理想，
配合 [整環](Integral_Domain.md)【證明 (a)】的 $\mathbf{Z}$ 是整環：

$$\mathbf{Z} \overset{\text{定義 2}}{=} \text{PID}$$

與投影片的「Every ideal in $\mathbf{Z}$ is a principal ideal」「$\mathbf{Z}$ is a PID」一致。

* 註：**除法原理是整個證明的引擎**。它保證「除不盡的餘數一定比除數小」，
  於是最小性立刻把餘數逼成 $0$。
  沒有除法原理的環（如 $\mathbf{Z}[x]$）就不一定是 PID ——
  見 [$\mathbf{Z}[x]$ 中的非主理想](Non_Principal_Ideal_in_Z_x.md)。

### (d) verify that the ideal generated by fifteen and twenty-one is principal

依【定義 1(b)】展開，再套貝祖等式：

$$\begin{gather*}
\left\langle 15, 21 \right\rangle &\overset{\text{定義 1(b)}}{=}& \left\{15m + 21n \ \middle|\ m, n \in \mathbf{Z}\right\} \\
&=& 15\mathbf{Z} + 21\mathbf{Z} \\
&\overset{\text{已知 3}}{=}& \gcd(15, 21)\,\mathbf{Z} \\
&=& 3\mathbf{Z} \\
&\overset{\text{定義 1(a)}}{=}& \langle 3 \rangle
\end{gather*}$$

與投影片一致。具體的貝祖係數是 $3 = 15 \times 3 + 21 \times \left(-2\right)$：

$$\begin{gather*}
15 \times 3 + 21 \times \left(-2\right) &=& 45 - 42 \\
&=& 3
\end{gather*}$$

* 註：這是【證明 (c)】的一個實例 —— $\left\langle 15, 21 \right\rangle$ 是 $\mathbf{Z}$ 的理想，
  依【證明 (c)】它必定是主理想，而生成元就是其中**最小的正元素**，
  也就是 $\gcd(15, 21) = 3$。**gcd 的理想論意義就是「最小的正元素」。**

### (e) disprove that the ideal generated by two indeterminates is principal

反設 $\left\langle x, y \right\rangle = \left\langle f \right\rangle$（【假設 1】）。
既然 $x$ 與 $y$ 都落在 $\left\langle f \right\rangle$ 裡，$f$ 必須同時整除兩者：

$$\begin{gather*}
x &\overset{\text{假設 1}}{\in}& \left\langle f \right\rangle \\
x &\overset{\text{定義 1(a)}}{=}& f g_1 \qquad \text{for some } g_1 \in \mathbf{Q}[x,y] \\
y &\overset{\text{定義 1(a)}}{=}& f g_2 \qquad \text{for some } g_2 \in \mathbf{Q}[x,y]
\end{gather*}$$

對第一式取總次數（【已知 4(a)】，$\mathbf{Q}[x,y]$ 為整環故次數可加）：

$$\begin{gather*}
1 = \deg x &\overset{\text{已知 4(a)}}{=}& \deg f + \deg g_1 \\
\deg f &\in& \left\{0, 1\right\}
\end{gather*}$$

**情形一：$\deg f = 1$。** 則 $\deg g_1 = 0$，即 $g_1$ 是非零常數 $c$，於是
$f = c^{-1}x$。同理由第二式 $f$ 也必須是 $y$ 的常數倍：

$$\begin{gather*}
f &=& c^{-1}x \qquad \text{(由第一式)} \\
1 = \deg y &\overset{\text{已知 4(a)}}{=}& \deg f + \deg g_2 = 1 + \deg g_2 \\
\deg g_2 &=& 0 \\
y &=& c^{-1}x \cdot g_2 \qquad \text{(} g_2 \text{ 為常數)} \\
y &\in& \left\{\text{$x$ 的常數倍}\right\}
\end{gather*}$$

但 $y$ 不可能是 $x$ 的常數倍（兩者是相異的未定元），矛盾。

**情形二：$\deg f = 0$。** 則 $f$ 是非零常數，在 $\mathbf{Q}$ 中可逆：

$$\begin{gather*}
\left\langle f \right\rangle &\overset{\text{定義 1(a)}}{=}& \mathbf{Q}[x, y] \qquad \text{(} f \text{ 可逆，見【證明 (a)】的註)} \\
1 &\in& \left\langle f \right\rangle \\
1 &\overset{\text{假設 1}}{\in}& \left\langle x, y \right\rangle \\
1 &\overset{\text{推導 1}}{=}& 0
\end{gather*}$$

最後一行矛盾（【推導 1】說 $\left\langle x,y \right\rangle$ 的元素常數項必為 $0$，而 $1$ 的常數項是 $1$）。

兩種情形都矛盾，故 $\left\langle x, y \right\rangle$ **不是**主理想，與投影片一致。

* 註：**$\mathbf{Q}[x,y]$ 因此不是 PID**，雖然 $\mathbf{Q}[x]$（單一未定元）是。
  「未定元多一個，PID 性質就沒了」是交換代數裡的標準現象。

## 意義與密碼學關聯 (Interpretation and Relevance to Cryptography)

### 主理想 = 「最大公因數的抽象版」

【證明 (d)】揭露了一個漂亮的對應：

$$\left\langle 15, 21 \right\rangle = \left\langle \gcd(15, 21) \right\rangle = \langle 3 \rangle$$

一般地，在 $\mathbf{Z}$ 裡：

$$\left\langle a, b \right\rangle = \left\langle \gcd(a, b) \right\rangle$$

**「兩個數的 gcd」的理想論定義就是「包含兩者的最小理想的生成元」。**
這個觀點讓 gcd 可以推廣到任何 PID —— 例如 $\mathbf{Q}[x]$ 裡兩個多項式的 gcd。

而【證明 (c)】說明了為什麼 gcd 在 $\mathbf{Z}$ 裡總是存在：
因為 $\mathbf{Z}$ 是 PID，$\left\langle a, b \right\rangle$ 必定由單一元素生成，
那個元素就是 gcd。

### 為什麼 PID 這個性質重要

PID 保證了幾件在密碼學裡天天用的事：

1. **gcd 存在且可算**（輾轉相除法）—— RSA 的金鑰產生要算 $\gcd\left(e, \varphi(n)\right)$；
2. **貝祖等式成立** —— 模逆元 $e^{-1} \bmod \varphi(n)$ 靠擴展歐幾里得演算法求出，
   而那正是在算貝祖係數；
3. **唯一分解成立**（PID $\Rightarrow$ UFD）—— 算術基本定理，整數分解問題的前提。

$\mathbf{Q}[x]$ 也是 PID（同樣有除法原理），所以**多項式的 gcd 與模逆元也可以算** ——
這是 $GF(2^8)$ 裡求乘法反元素的演算法基礎，也就是 AES S-box 第一步要做的事。

### $\mathbf{Z}[x]$ 與 $\mathbf{Q}[x,y]$ 都不是 PID

兩個反例值得並列：

| 環 | 非主理想的例子 | 出處 |
|---|---|---|
| $\mathbf{Q}[x, y]$ | $\left\langle x, y \right\rangle$ | 【證明 (e)】 |
| $\mathbf{Z}[x]$ | $\left\langle 2, x \right\rangle$（常數項為偶數） | [$\mathbf{Z}[x]$ 中的非主理想](Non_Principal_Ideal_in_Z_x.md) |

兩者壞掉的原因相同：**需要兩個「互不相干」的生成元，一個不夠**。
$\mathbf{Q}[x,y]$ 的問題是未定元太多，$\mathbf{Z}[x]$ 的問題是係數環 $\mathbf{Z}$ 不是體
（$2$ 不可逆）。

**修法也對應**：$\mathbf{Q}[x]$（一個未定元 + 係數是體）就是 PID。
這就是為什麼密碼學用的多項式環一律取係數在**體**上（$\mathbf{Z}_p$ 或 $GF(2^n)$），
而且只用**一個**未定元。

### 密碼學上的對應：$\left\langle f(x) \right\rangle$ 是有限體的建構方式

AES 的 $GF(2^8)$ 定義為：

$$GF(2^8) = \mathbf{Z}_2[x] \,\big/\, \left\langle x^8 + x^4 + x^3 + x + 1 \right\rangle$$

那個 $\left\langle \cdot \right\rangle$ 就是本檔的主理想。同樣地 Kyber 用

$$R_q = \mathbf{Z}_q[x] \,\big/\, \left\langle x^{256} + 1 \right\rangle$$

**兩者都是「多項式環除以一個主理想」**。能這樣做的前提是
$\mathbf{Z}_p[x]$ 是 PID —— 每個理想都由單一多項式生成，
所以「模一個多項式」這個動作才有意義。

為什麼模**不可約**多項式會得到體則見

### 程式思維

```python
# 貝祖係數 = 主理想生成元的證據
def extended_gcd(a, b):
    if b == 0:
        return a, 1, 0
    g, x, y = extended_gcd(b, a % b)
    return g, y, x - (a // b) * y

g, m, n = extended_gcd(15, 21)
assert 15 * m + 21 * n == g == 3        # <15,21> = <3>
```

`extended_gcd` 回傳的 `(g, m, n)` 就是【證明 (d)】那一行
$3 = 15 \times 3 + 21 \times \left(-2\right)$ 的程式版本。
RSA 求私鑰 `d = pow(e, -1, phi)` 底層跑的正是這個演算法。
