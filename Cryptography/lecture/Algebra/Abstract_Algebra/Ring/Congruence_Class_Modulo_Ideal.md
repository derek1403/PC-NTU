# Congruence Class Modulo an Ideal (模理想的同餘類)

+++

## 證明目標:

`Algebra.pdf` p.38–39。把小學學的「除以 $4$ 的餘數」推廣到任意環的任意理想 ——
而且會發現它**就是** [陪集](../Group/Coset.md) 換了個名字。

* (a) 模理想的同餘是一個**等價關係**：

$$a \equiv b \pmod{I} \quad \overset{\text{def}}{\Longleftrightarrow} \quad a - b \in I$$

* (b) 同餘類恰好就是加法群的陪集：

$$a + I = \left\{a + c \ \middle|\ c \in I\right\} = \left\{b \in R \ \middle|\ b \equiv a \pmod{I}\right\}$$

* (c) 整數的同餘是本定義取 $R = \mathbf{Z}$、$I = \left\langle m \right\rangle$ 的特例：

$$a \equiv b \pmod{m} \quad \Longleftrightarrow \quad m \mid \left(a - b\right) \quad \Longleftrightarrow \quad a - b \in \left\langle m \right\rangle$$

* (d) 驗證投影片 p.39 的例子：$R = \mathbf{Z}$、$I = \left\langle 4 \right\rangle = 4\mathbf{Z}$ 恰有四個同餘類。

* $R$ : 環的底層集合 (The underlying set of the ring) $[\text{集合}]$
* $I$ : $R$ 的理想 (An ideal of $R$) $[I \trianglelefteq R]$
* $a,\ b$ : 環元素 (Ring elements) $[a, b \in R]$
* $a + I$ : $a$ 模 $I$ 的同餘類 (The congruence class of $a$ modulo $I$) $[a + I \subseteq R]$
* $m$ : 整數模數 (An integer modulus) $[m \in \mathbf{Z}]$
* 註：投影片在 p.38 明說「The congruent class $a + I$ is a **coset** of $I$ in $R$」——
  本檔【證明 (b)】把這句話證出來。**同餘類就是陪集**，
  所以 [陪集分割](../Group/Coset_Partition.md) 的三條引理在這裡全部可以直接用。
* 註：本檔只處理「怎麼分類」，**不處理「分類之後怎麼運算」** ——
  那是 [商環](Quotient_Ring.md) 的工作，而且需要理想的吸收性才成立。
* 註：加法記號下左右陪集永遠相等（[陪集](../Group/Coset.md)【定義 2】），
  故本檔不必區分 $a + I$ 與 $I + a$。

+++

## 假設與已知 (Assumptions & Preliminaries)

* **【已知 1】 [理想的定義 (Definition of an ideal)](https://derek1403.github.io/PC-NTU/Cryptography/_build/html/lecture/Algebra/Abstract_Algebra/Ring/Ideal.html#assumptions-preliminaries)：** 已於本章 [理想](Ideal.md)【定義 1】給出，此處直接引用

  * (a) 加法子群（特別是含 $0$、對減法封閉）：

    $$0 \in I, \qquad a - b \in I \ \text{ for all } a, b \in I$$

  * (b) 吸收性：

    $$ar \in I \qquad \text{for all } a \in I,\ r \in R$$

  * $I$ : $R$ 的理想 (An ideal of $R$) $[I \trianglelefteq R]$
  * $R$ : 母環的底層集合 (The underlying set of the ambient ring) $[\text{集合}]$
  * $a,\ b$ : 理想中的元素 (Elements of the ideal) $[a, b \in I]$
  * $r$ : 母環中的元素 (An element of the ambient ring) $[r \in R]$

* **【已知 2】 [陪集的定義與分割性質 (Cosets and the partition property)](https://derek1403.github.io/PC-NTU/Cryptography/_build/html/lecture/Algebra/Abstract_Algebra/Group/Coset_Partition.html#d-proof-that-the-left-cosets-form-a-partition)：** 已於本章 [陪集](../Group/Coset.md)【定義 1】【定義 2】與 [陪集分割](../Group/Coset_Partition.md)【證明 (d)】給出並證明，此處直接引用不再重證

  * (a) 加法記號的陪集：

    $$g + H = \left\{g + h \ \middle|\ h \in H\right\}$$

  * (b) 陪集構成分割（不重不漏）：

    $$\bigcup_{g \in G} \left(g + H\right) = G, \qquad \left(g_1 + H\right) \cap \left(g_2 + H\right) = \varnothing \ \text{ 或 } \ g_1 + H = g_2 + H$$

  * (c) 陪集相等的判別式：

    $$g_1 + H = g_2 + H \quad \Longleftrightarrow \quad -g_1 + g_2 \in H$$

  * $G$ : 母群的底層集合 (The underlying set of the ambient group) $[\text{集合}]$
  * $H$ : $G$ 的子群 (A subgroup of $G$) $[H \le G]$
  * $g,\ g_1,\ g_2$ : 陪集代表元 (Coset representatives) $[g, g_1, g_2 \in G]$
  * $h$ : 子群中的元素 (An element of the subgroup) $[h \in H]$
  * 註：(c) 是 [陪集相等的充要條件](../Group/Coset_Equality_Criterion.md)【證明 (a)(b)】的加法版本
    （$g_1^{-1} * g_2$ 改寫成 $-g_1 + g_2$）。

* **【已知 3】 [整除、同餘與主理想 (Divisibility, congruence, and principal ideals)](https://derek1403.github.io/PC-NTU/Cryptography/_build/html/lecture/Algebra/Abstract_Algebra/Number_Sets_and_Notation.html#assumptions-preliminaries)：** 已於本章 [數系與符號約定](../Number_Sets_and_Notation.md)【已知 1(a)】【已知 2】與 [主理想](Principal_Ideal.md)【定義 1(a)】給出，此處直接引用

  * (a) 整除與同餘：

    $$m \mid k \quad \overset{\text{def}}{\Longleftrightarrow} \quad \exists\, t \in \mathbf{Z},\ k = mt, \qquad a \equiv b \pmod{m} \quad \overset{\text{def}}{\Longleftrightarrow} \quad m \mid \left(a - b\right)$$

  * (b) 主理想：

    $$\left\langle m \right\rangle = m\mathbf{Z} = \left\{mt \ \middle|\ t \in \mathbf{Z}\right\}$$

  * $m,\ k$ : 整數 (Integers) $[m, k \in \mathbf{Z}]$
  * $a,\ b$ : 整數 (Integers) $[a, b \in \mathbf{Z}]$
  * $t$ : 整數倍數 (Integer multiplier) $[t \in \mathbf{Z}]$
  * $\left\langle m \right\rangle$ : 由 $m$ 生成的主理想 (The principal ideal generated by $m$) $[\left\langle m \right\rangle \trianglelefteq \mathbf{Z}]$

* **【定義 1】 模理想的同餘 (Congruence modulo an ideal)：** 兩個元素的差落在理想裡

  $$a \equiv b \pmod{I} \quad \overset{\text{def}}{\Longleftrightarrow} \quad a - b \in I$$

  * $a,\ b$ : 環元素 (Ring elements) $[a, b \in R]$
  * $I$ : $R$ 的理想 (An ideal of $R$) $[I \trianglelefteq R]$
  * $R$ : 環的底層集合 (The underlying set of the ring) $[\text{集合}]$
  * 註：投影片 p.38 的用語是「$a$ is **congruent to** $b$ modulo $I$」。

* **【定義 2】 同餘類 (Congruence class)：** 與 $a$ 同餘的元素全體

  $$a + I \overset{\text{def}}{=} \left\{b \in R \ \middle|\ b \equiv a \pmod{I}\right\}$$

  * $a + I$ : $a$ 模 $I$ 的同餘類 (The congruence class of $a$ modulo $I$) $[a + I \subseteq R]$
  * $a,\ b$ : 環元素 (Ring elements) $[a, b \in R]$
  * $I$ : $R$ 的理想 (An ideal of $R$) $[I \trianglelefteq R]$
  * 註：記號寫成 $a + I$ 是**先射箭再畫靶** —— 它長得像陪集，而【證明 (b)】會證明它確實是陪集。
    在那之前，這個記號只是一個名字。

## 證明:

### (a) proof that congruence modulo an ideal is an equivalence relation

三條性質逐一檢查。

**自反性** $a \equiv a$：

$$\begin{gather*}
a - a &=& 0 \\
0 &\overset{\text{已知 1(a)}}{\in}& I \\
a &\overset{\text{定義 1}}{\equiv}& a \pmod{I}
\end{gather*}$$

**對稱性** $a \equiv b \Rightarrow b \equiv a$：

$$\begin{gather*}
a - b &\overset{\text{定義 1}}{\in}& I \\
0 - \left(a - b\right) &\overset{\text{已知 1(a)}}{\in}& I \qquad \text{(減法封閉，取 } 0 \in I\text{)} \\
b - a &\in& I \\
b &\overset{\text{定義 1}}{\equiv}& a \pmod{I}
\end{gather*}$$

**遞移性** $a \equiv b,\ b \equiv c \Rightarrow a \equiv c$：

$$\begin{gather*}
a - b &\overset{\text{定義 1}}{\in}& I \\
b - c &\overset{\text{定義 1}}{\in}& I \\
c - b &\overset{\text{已知 1(a)}}{\in}& I \qquad \text{(對稱性，同上)} \\
\left(a - b\right) - \left(c - b\right) &\overset{\text{已知 1(a)}}{\in}& I \qquad \text{(減法封閉)} \\
a - c &\in& I \\
a &\overset{\text{定義 1}}{\equiv}& c \pmod{I}
\end{gather*}$$

三條全中，故 $\equiv \pmod{I}$ 是等價關係。

* 註：**三條性質全部只用到【已知 1(a)】**（加法子群），完全沒用到吸收性【已知 1(b)】。
  這代表分類這件事對任何**加法子群**都成立，不必是理想 ——
  吸收性要到 [商環](Quotient_Ring.md) 定義乘法時才派上用場。

### (b) proof that a congruence class is a coset

用雙向包含，證明【定義 2】的集合恰好就是【已知 2(a)】的陪集。

**($\subseteq$)** 設 $b \equiv a \pmod I$：

$$\begin{gather*}
b - a &\overset{\text{定義 1}}{\in}& I \\
b - a &=& c \qquad \text{for some } c \in I \\
b &=& a + c \\
b &\overset{\text{已知 2(a)}}{\in}& \left\{a + c \ \middle|\ c \in I\right\}
\end{gather*}$$

**($\supseteq$)** 設 $b = a + c$，$c \in I$：

$$\begin{gather*}
b - a &=& c \\
b - a &\in& I \\
b &\overset{\text{定義 1}}{\equiv}& a \pmod{I} \\
b &\overset{\text{定義 2}}{\in}& a + I
\end{gather*}$$

兩個包含合起來：

$$a + I = \left\{a + c \ \middle|\ c \in I\right\}$$

**這正是 $I$ 作為 $\left(R, +\right)$ 的子群的陪集**（【已知 2(a)】），與投影片 p.38 的最後一行一致。

* 註：**一旦確認是陪集，[陪集分割](../Group/Coset_Partition.md) 的三條引理全部免費取得**：
  * 每個同餘類一樣大（與 $I$ 等勢）；
  * 兩個同餘類要嘛相同要嘛不相交；
  * 所有同餘類合起來就是 $R$。

  這三件事就是「餘數把整數分成幾類、每類一樣多、不重不漏」的精確版本。
* 註：由【已知 2(c)】，兩個同餘類相等的判別式是 $-a + b \in I$，
  也就是 $b - a \in I$，與【定義 1】完全一致 —— **判別式與同餘的定義是同一件事**。

### (c) proof that integer congruence is the special case of a principal ideal

取 $R = \mathbf{Z}$、$I = \left\langle m \right\rangle$，把【定義 1】展開：

$$\begin{gather*}
a \equiv b \pmod{\left\langle m \right\rangle} &\overset{\text{定義 1}}{\Longleftrightarrow}& a - b \in \left\langle m \right\rangle \\
a - b \in \left\langle m \right\rangle &\overset{\text{已知 3(b)}}{\Longleftrightarrow}& a - b = mt \ \text{ for some } t \in \mathbf{Z} \\
a - b = mt &\overset{\text{已知 3(a)}}{\Longleftrightarrow}& m \mid \left(a - b\right) \\
m \mid \left(a - b\right) &\overset{\text{已知 3(a)}}{\Longleftrightarrow}& a \equiv b \pmod{m}
\end{gather*}$$

四行串起來，**模理想的同餘在 $R = \mathbf{Z}$ 時就退化成小學的模 $m$ 同餘**，
與投影片 p.38 的「cf. $a \equiv b \pmod m$ iff $m \mid (a-b)$ iff $a - b \in \left\langle m \right\rangle$ in $\mathbf{Z}$」一致。

### (d) verify the four congruence classes modulo four

投影片 p.39 取 $R = \mathbf{Z}$、$I = \left\langle 4 \right\rangle = 4\mathbf{Z}$。依【證明 (b)】逐一列出：

$$\begin{gather*}
I = 0 + I &\overset{\text{證明 (b)}}{=}& \left\{\dots, -8, -4, 0, 4, 8, \dots\right\} \\
1 + I &\overset{\text{證明 (b)}}{=}& \left\{\dots, -7, -3, 1, 5, 9, \dots\right\} \\
2 + I &\overset{\text{證明 (b)}}{=}& \left\{\dots, -6, -2, 2, 6, 10, \dots\right\} \\
3 + I &\overset{\text{證明 (b)}}{=}& \left\{\dots, -5, -1, 3, 7, 11, \dots\right\}
\end{gather*}$$

與投影片列出的四個集合完全一致。**恰好只有四個**，因為第五個會繞回第一個：

$$\begin{gather*}
4 - 0 &=& 4 \\
4 &\in& 4\mathbf{Z} \\
4 &\overset{\text{定義 1}}{\equiv}& 0 \pmod{4\mathbf{Z}} \\
4 + I &\overset{\text{已知 2(c)}}{=}& 0 + I
\end{gather*}$$

四個同餘類互不相交且聯集為 $\mathbf{Z}$（【已知 2(b)】），構成 $\mathbf{Z}$ 的一個分割。

* 註：投影片接著說「It seems natural to define $+$ and $\times$ on them as
  $\left(2+I\right)+\left(3+I\right) = \left(1+I\right)$、$\left(2+I\right)\times\left(3+I\right) = \left(2+I\right)$」。
  **「seems natural」這三個字其實藏著一個要證明的東西** ——
  這樣定義是否良定義（換一個代表元會不會得到不同答案）？
  這正是 [商環](Quotient_Ring.md) 要處理的事，而乘法的良定義**必須**用到理想的吸收性。

## 意義與密碼學關聯 (Interpretation and Relevance to Cryptography)

### 從小學餘數到抽象代數的完整路徑

本檔把一條貫穿全章的線索接了起來：

$$\underbrace{\text{除以 4 的餘數}}_{\text{小學}} \ = \ \underbrace{a \equiv b \pmod 4}_{\text{數論}} \ = \ \underbrace{a + 4\mathbf{Z}}_{\text{陪集}} \ = \ \underbrace{a + \left\langle 4 \right\rangle}_{\text{模理想的同餘類}}$$

四種說法**指的是同一件事**，只是抽象層級不同：

| 層級 | 語言 | 出處 |
|---|---|---|
| 小學 | 餘數 | — |
| 數論 | $m \mid (a-b)$ | [數系與符號約定](../Number_Sets_and_Notation.md)【已知 2】 |
| 群論 | 陪集 $a + H$ | [陪集](../Group/Coset.md) |
| 環論 | 同餘類 $a + I$ | 本檔 |

**抽象化買到的是什麼？** 買到的是「同一套定理可以用在別的地方」。
$R = \mathbf{Z}_q[x]$、$I = \left\langle x^{256}+1 \right\rangle$ 時，
上面每一條都照樣成立 —— 而那正是 Kyber 在做的事。

### 為什麼同餘類的個數 = 理想的指標

由【證明 (b)】與 [拉格朗日定理](../Group/Lagrange_Theorem.md)：

$$\text{同餘類的個數} = \left[R : I\right] = \frac{\left|R\right|}{\left|I\right|} \qquad \left(R \ \text{有限時}\right)$$

$R = \mathbf{Z}$、$I = 4\mathbf{Z}$ 時 $R$ 是無限的，但指標仍然是 $4$（【證明 (d)】數出來的）。
一般地：

$$\left[\mathbf{Z} : n\mathbf{Z}\right] = n$$

這個數字就是 $\left|\mathbf{Z}_n\right|$ —— **模 $n$ 的世界有幾個元素，由指標決定**。

在 $GF(2^8) = \mathbf{Z}_2[x]/\left\langle f \right\rangle$（$\deg f = 8$）裡，
同樣的計數給出 $2^8 = 256$ 個同餘類 —— 這就是為什麼 AES 的一個「位元組」
恰好是 $GF(2^8)$ 的一個元素。

### 代表元的選擇：實作上的正規化

一個同餘類有無限多個代表元（$\dots, 1, 5, 9, \dots$ 都代表 $1 + 4\mathbf{Z}$）。
實作必須挑一個**標準代表元**，否則沒辦法比較兩個值是否相等。

| 環 | 標準代表元 | 程式 |
|---|---|---|
| $\mathbf{Z}/n\mathbf{Z}$ | $0, 1, \dots, n-1$ | `x % n` |
| $\mathbf{Z}/n\mathbf{Z}$（另一種慣例） | $-\lfloor n/2 \rfloor, \dots, \lfloor n/2 \rfloor$ | 中心化表示 |
| $\mathbf{Z}_q[x]/\left\langle x^N+1 \right\rangle$ | 次數 $< N$ 的多項式 | 多項式除法取餘式 |

**Kyber 用的是中心化表示**（第二列），因為它的安全性分析要用到「係數的絕對值小」這個性質，
而 $0..q-1$ 的表示會讓 $q-1$ 看起來很大，實際上它等於 $-1$。

**同一個同餘類，換個代表元就換一個「大小」** —— 這在格密碼裡是關鍵，
因為格密碼的困難性正是建立在「找到範數最小的代表元」這個問題上。

### 程式思維

```python
# 同餘類的判斷：定義 1
def congruent(a, b, n):
    return (a - b) % n == 0          # a - b ∈ <n>

# 三條等價關係（證明 (a)）
assert congruent(a, a, n)                                     # 自反
assert congruent(a, b, n) == congruent(b, a, n)               # 對稱
# 遞移：congruent(a,b) and congruent(b,c) => congruent(a,c)

# 正規化到標準代表元
def normalize(a, n):
    return a % n                     # 挑 0..n-1 那一個
```

`(a - b) % n == 0` 就是【定義 1】的直接翻譯。
注意 Python 的 `%` 對負數回傳非負值，恰好就是「標準代表元」的慣例 ——
C 語言的 `%` 則會保留符號，所以 C 的模算術實作必須手動修正，
這是跨語言移植密碼程式碼時的經典坑。
