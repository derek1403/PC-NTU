# Simple Extension (單擴張)

+++

## 證明目標:

`Algebra.pdf` p.53。把**一個**新元素丟進體裡，會長出什麼？
答案是「所有用它算得出來的有理式」—— 而且那恰好是一個體。

* (a) 投影片的 Proposition：對任意 $a \in L$，

$$K(a) = \left\{\frac{f(a)}{g(a)} \ \middle|\ f, g \in K[x],\ g(a) \neq 0\right\} \ \text{是體}$$

* (b) $K(a)$ 是 $L$ 中**同時含 $K$ 與 $a$ 的最小子體**（投影片未明說，但這是「生成」的精確意思）。
* (c) 驗證投影片的例子 —— 兩種寫法其實是同一個集合：

$$\mathbf{Q}\!\left(\sqrt{2}\right) = \left\{\frac{a + b\sqrt{2}}{c + d\sqrt{2}} \ \middle|\ a,b,c,d \in \mathbf{Q},\ c + d\sqrt{2} \neq 0\right\} = \left\{p + q\sqrt{2} \ \middle|\ p, q \in \mathbf{Q}\right\}$$

* $K$ : 基體 (The base field) $[\text{體}]$
* $L$ : 大體 (The larger field) $[K \subseteq L]$
* $a$ : 被添進來的元素 (The adjoined element) $[a \in L]$
* $K(a)$ : 由 $a$ 生成的單擴張 (The simple extension generated by $a$) $[K \subseteq K(a) \subseteq L]$
* $f,\ g$ : $K$ 上的多項式 (Polynomials over $K$) $[f, g \in K[x]]$
* 註：記號要分清楚 —— $K[a]$（方括號）是**多項式**的值全體、
  $K(a)$（圓括號）是**有理式**的值全體。一般 $K[a] \subseteq K(a)$，
  而 $a$ 是**代數元**時兩者相等（【證明 (c)】的 $\mathbf{Q}\!\left(\sqrt{2}\right)$ 就是這種情形）。
* 註：投影片把 $\mathbf{Q}\!\left(\sqrt{2}\right)$ 寫成分式的形式，
  而 [塔定理](Tower_Law.md)【定義 2(a)】用的是 $\left\{a + b\sqrt{2}\right\}$ ——
  【證明 (c)】證明兩者相等，兩檔的用法因此一致。
* 註：[本原元定理](Primitive_Element_Theorem.md) 會說：
  特徵 $0$ 的有限擴張**全部**是單擴張。

## 假設與已知 (Assumptions & Preliminaries)

* **【已知 1】 [子體判別法 (Subfield criterion)](https://derek1403.github.io/PC-NTU/Cryptography/_build/html/lecture/Algebra/Abstract_Algebra/Field/Subfield_and_Field_Extension.html#a-proof-of-the-subfield-criterion)：** 已於本章 [子體與體擴張](Subfield_and_Field_Extension.md)【證明 (a)】完整證明，此處直接引用不再重證

  $$K \ \text{是 } F \text{ 的子體} \quad \Longleftrightarrow \quad \left|K\right| \ge 2, \quad u - v \in K, \quad uv^{-1} \in K \ \left(v \neq 0\right)$$

  * $K$ : $F$ 的子集 (A subset of $F$) $[K \subseteq F]$
  * $F$ : 大體的底層集合 (The underlying set of the larger field) $[\text{集合}]$
  * $u,\ v$ : 子集中的元素 (Elements of the subset) $[u, v \in K]$

* **【已知 2】 [多項式環的運算 (Operations in the polynomial ring)](https://derek1403.github.io/PC-NTU/Cryptography/_build/html/lecture/Algebra/Abstract_Algebra/Ring/Ring_Examples.html#e-verify-that-the-polynomials-form-a-ring)：** 已於本章 [環的例子](../Ring/Ring_Examples.md)【定義 2】【證明 (e)】給出並證明，此處直接引用不再重證

  * (a) $K[x]$ 對加減乘封閉：

    $$f \pm g \in K[x], \qquad fg \in K[x]$$

  * (b) 求值是環同態（代入 $x = a$ 保運算）：

    $$\left(f \pm g\right)(a) = f(a) \pm g(a), \qquad \left(fg\right)(a) = f(a)\,g(a)$$

  * $K[x]$ : 多項式環 (The polynomial ring) $[\text{集合}]$
  * $f,\ g$ : 多項式 (Polynomials) $[f, g \in K[x]]$
  * $a$ : 代入的值 (The value substituted) $[a \in L]$
  * 註：(b) 的成立需要 $L$ 交換（體必交換），否則代入會出問題。

* **【已知 3】 [體的定義與無零因子 (Field definition and absence of zero divisors)](https://derek1403.github.io/PC-NTU/Cryptography/_build/html/lecture/Algebra/Abstract_Algebra/Field/Field_Definition.html#d-proof-that-every-field-is-an-integral-domain)：** 已於本章 [體的定義](Field_Definition.md)【定義 1】【證明 (d)】給出並證明，此處直接引用不再重證

  * (a) 體公理：

    $$\left(F, +\right) \ \text{阿貝爾群}, \quad ab = ba, \quad \forall\, a \neq 0,\ \exists\, a^{-1}$$

  * (b) 無零因子：

    $$ab = 0 \quad \Longrightarrow \quad a = 0 \ \text{ 或 } \ b = 0$$

  * $F$ : 體的底層集合 (The underlying set of the field) $[\text{集合}]$
  * $a,\ b$ : 體元素 (Field elements) $[a, b \in F]$

* **【已知 4】 [$\sqrt{2}$ 是無理數 (Irrationality of the square root of two)](https://derek1403.github.io/PC-NTU/Cryptography/_build/html/lecture/Algebra/Abstract_Algebra/Field/Tower_Law.html#assumptions-preliminaries)：** 已於本章 [塔定理](Tower_Law.md)【已知 3(a)】引用，此處再次引用

  $$\sqrt{2} \notin \mathbf{Q}$$

  * $\sqrt{2}$ : 二的平方根 (The square root of two) $[\sqrt{2} \in \mathbf{R}]$

* **【定義 1】 單擴張 (Simple extension)：** 由單一個元素生成的擴張

  * (a) 添加一個元素得到的集合：

    $$K(a) \overset{\text{def}}{=} \left\{\frac{f(a)}{g(a)} \ \middle|\ f, g \in K[x],\ g(a) \neq 0\right\}$$

  * (b) 單擴張：

    $$L : K \ \text{為單擴張} \quad \overset{\text{def}}{\Longleftrightarrow} \quad \exists\, a \in L \ \text{ with } \ L = K(a)$$

  * $K(a)$ : 由 $a$ 生成的單擴張 (The simple extension generated by $a$) $[K(a) \subseteq L]$
  * $K$ : 基體 (The base field) $[\text{體}]$
  * $L$ : 大體 (The larger field) $[K \subseteq L]$
  * $a$ : 被添進來的元素 (The adjoined element) $[a \in L]$
  * $f,\ g$ : $K$ 上的多項式 (Polynomials over $K$) $[f, g \in K[x]]$
  * 註：分式 $\dfrac{f(a)}{g(a)}$ 是在 **$L$ 裡**做除法，合法性由 $g(a) \neq 0$ 與 $L$ 是體保證。
  * 註：(b) 裡的 $a$ 稱為該擴張的**本原元 (primitive element)**，
    見 [本原元定理](Primitive_Element_Theorem.md)。

* **【定義 2】 添進 $\sqrt{2}$ 的兩種寫法 (Two descriptions of the field obtained by adjoining the square root of two)：** 【證明 (c)】要比較的兩個集合

  * (a) 投影片的分式寫法：

    $$S_1 \overset{\text{def}}{=} \left\{\frac{a + b\sqrt{2}}{c + d\sqrt{2}} \ \middle|\ a,b,c,d \in \mathbf{Q},\ c + d\sqrt{2} \neq 0\right\}$$

  * (b) 線性組合寫法：

    $$S_2 \overset{\text{def}}{=} \left\{p + q\sqrt{2} \ \middle|\ p, q \in \mathbf{Q}\right\}$$

  * $S_1,\ S_2$ : 兩種寫法的集合 (The two described sets) $[S_1, S_2 \subseteq \mathbf{R}]$
  * $a,\ b,\ c,\ d,\ p,\ q$ : 有理係數 (Rational coefficients) $[\in \mathbf{Q}]$

* **【推導 1】 分母不為零時共軛積也不為零 (The conjugate product is non-zero)：** 【證明 (c)】要用。
  分母有理化的合法性靠這一條

  $$\begin{gather*}
  \left(c + d\sqrt{2}\right)\left(c - d\sqrt{2}\right) &=& c^2 - 2d^2 \\
  c^2 - 2d^2 = 0,\ d \neq 0 &\Longrightarrow& \sqrt{2} = \left|\frac{c}{d}\right| \in \mathbf{Q} \\
  \sqrt{2} &\overset{\text{已知 4}}{\notin}& \mathbf{Q} \\
  c^2 - 2d^2 = 0,\ d = 0 &\Longrightarrow& c = 0 \\
  c = d = 0 &\Longrightarrow& c + d\sqrt{2} = 0 \\
  c + d\sqrt{2} \neq 0 &\Longrightarrow& c^2 - 2d^2 \neq 0
  \end{gather*}$$

  * $c,\ d$ : 有理係數 (Rational coefficients) $[c, d \in \mathbf{Q}]$
  * 註：兩種情形（$d \neq 0$ 與 $d = 0$）都推出「若 $c^2-2d^2 = 0$ 則 $c = d = 0$」，
    取逆否即得最後一行。
  * 註：**$c - d\sqrt{2}$ 稱為 $c + d\sqrt{2}$ 的共軛**，與複數共軛是同一個想法 ——
    乘上共軛就把根號消掉。

## 證明:

### (a) proof that the simple extension is a field

依【已知 1】三條檢查 $K(a) \subseteq L$。

**至少兩個元素**：取 $f = 0, g = 1$ 得 $0$；取 $f = g = 1$ 得 $1$：

$$\begin{gather*}
\frac{0}{1} = 0 &\overset{\text{定義 1(a)}}{\in}& K(a) \\
\frac{1}{1} = 1 &\overset{\text{定義 1(a)}}{\in}& K(a)
\end{gather*}$$

**對減法封閉**：通分即可，分母仍是兩個非零值的乘積：

$$\begin{gather*}
\frac{f_1(a)}{g_1(a)} - \frac{f_2(a)}{g_2(a)} &=& \frac{f_1(a)g_2(a) - f_2(a)g_1(a)}{g_1(a)g_2(a)} \\
f_1 g_2 - f_2 g_1 &\overset{\text{已知 2(a)}}{\in}& K[x] \\
g_1 g_2 &\overset{\text{已知 2(a)}}{\in}& K[x] \\
\left(g_1 g_2\right)(a) = g_1(a)g_2(a) &\overset{\text{已知 3(b)}}{\neq}& 0 \qquad \text{(兩個非零元素相乘非零)} \\
\frac{f_1(a)}{g_1(a)} - \frac{f_2(a)}{g_2(a)} &\overset{\text{定義 1(a),已知 2(b)}}{\in}& K(a)
\end{gather*}$$

**對除法封閉**：分子分母交叉相乘，注意除數非零時分子也非零：

$$\begin{gather*}
\frac{f_1(a)}{g_1(a)} \Bigg/ \frac{f_2(a)}{g_2(a)} &=& \frac{f_1(a)g_2(a)}{g_1(a)f_2(a)} \\
\frac{f_2(a)}{g_2(a)} \neq 0 &\Longrightarrow& f_2(a) \neq 0 \\
g_1(a)f_2(a) &\overset{\text{已知 3(b)}}{\neq}& 0 \\
f_1 g_2,\ g_1 f_2 &\overset{\text{已知 2(a)}}{\in}& K[x] \\
\frac{f_1(a)}{g_1(a)} \Bigg/ \frac{f_2(a)}{g_2(a)} &\overset{\text{定義 1(a),已知 2(b)}}{\in}& K(a)
\end{gather*}$$

三條全中，故 $K(a)$ 是 $L$ 的子體，即 $K(a)$ 是體，與投影片的 Proposition 一致。

* 註：**【已知 3(b)】（體無零因子）用了兩次**，都是為了保證通分後的分母仍然非零。
  這是整個證明唯一需要 $L$ 是體（而非只是環）的地方。

### (b) proof that the simple extension is the smallest such subfield

設 $M$ 是 $L$ 的任一子體且 $K \subseteq M$、$a \in M$。要證 $K(a) \subseteq M$。

$M$ 對加減乘封閉，且含 $K$ 的所有元素與 $a$，故含所有 $K$-係數多項式在 $a$ 的值：

$$\begin{gather*}
c \in K \subseteq M, \quad a &\in& M \\
c\,a^{i} &\overset{\text{已知 1}}{\in}& M \qquad \text{(乘法封閉)} \\
f(a) = \sum_i c_i a^{i} &\overset{\text{已知 1}}{\in}& M \qquad \text{(加法封閉)} \\
\frac{f(a)}{g(a)} &\overset{\text{已知 1}}{\in}& M \qquad \text{(除法封閉，} g(a) \neq 0\text{)} \\
K(a) &\overset{\text{定義 1(a)}}{\subseteq}& M
\end{gather*}$$

而 $K(a)$ 自己就是一個含 $K$ 與 $a$ 的子體（【證明 (a)】，且取 $f = c$、$g = 1$ 得 $K \subseteq K(a)$、
取 $f = x$、$g = 1$ 得 $a \in K(a)$）。故：

$$K(a) = \bigcap\left\{M \ \middle|\ M \ \text{是 } L \text{ 的子體},\ K \subseteq M,\ a \in M\right\}$$

**$K(a)$ 是含 $K$ 與 $a$ 的最小子體**，這就是「由 $a$ 生成」的精確意思。

### (c) verify that the two descriptions of the quadratic field coincide

用雙向包含證 $S_1 = S_2$（【定義 2】）。

**($\supseteq$)** $S_2$ 的元素取分母為 $1$ 即得：

$$\begin{gather*}
p + q\sqrt{2} &=& \frac{p + q\sqrt{2}}{1 + 0\sqrt{2}} \\
1 + 0\sqrt{2} = 1 &\neq& 0 \\
p + q\sqrt{2} &\overset{\text{定義 2(a)}}{\in}& S_1
\end{gather*}$$

**($\subseteq$)** 分母有理化 —— 上下同乘共軛，由【推導 1】分母變成非零有理數：

$$\begin{gather*}
\frac{a + b\sqrt{2}}{c + d\sqrt{2}} &=& \frac{\left(a + b\sqrt{2}\right)\left(c - d\sqrt{2}\right)}{\left(c + d\sqrt{2}\right)\left(c - d\sqrt{2}\right)} \\
&\overset{\text{推導 1}}{=}& \frac{\left(a + b\sqrt{2}\right)\left(c - d\sqrt{2}\right)}{c^2 - 2d^2} \\
&=& \frac{\left(ac - 2bd\right) + \left(bc - ad\right)\sqrt{2}}{c^2 - 2d^2} \\
&=& \frac{ac - 2bd}{c^2 - 2d^2} + \frac{bc - ad}{c^2 - 2d^2}\sqrt{2}
\end{gather*}$$

兩個係數都是有理數（【推導 1】保證分母非零），故：

$$\begin{gather*}
\frac{ac - 2bd}{c^2 - 2d^2},\ \frac{bc - ad}{c^2 - 2d^2} &\in& \mathbf{Q} \\
\frac{a + b\sqrt{2}}{c + d\sqrt{2}} &\overset{\text{定義 2(b)}}{\in}& S_2
\end{gather*}$$

兩個包含合起來：

$$\mathbf{Q}\!\left(\sqrt{2}\right) = S_1 = S_2 = \left\{p + q\sqrt{2} \ \middle|\ p, q \in \mathbf{Q}\right\}$$

與投影片一致，也與 [塔定理](Tower_Law.md)【定義 2(a)】的寫法一致。

* 註：**分母有理化就是在算 $\left(c+d\sqrt{2}\right)^{-1}$**：

  $$\left(c + d\sqrt{2}\right)^{-1} = \frac{c - d\sqrt{2}}{c^2 - 2d^2}$$

  這正是【證明 (a)】保證存在的那個反元素的**顯式公式**。
* 註：結論說明 $\mathbf{Q}\!\left[\sqrt{2}\right] = \mathbf{Q}\!\left(\sqrt{2}\right)$ ——
  多項式的值全體與有理式的值全體**相同**。這是因為 $\sqrt{2}$ 是**代數元**
  （滿足 $x^2 - 2 = 0$）。若 $a$ 是超越元（如 $\pi$），兩者就不相等了。

## 意義與密碼學關聯 (Interpretation and Relevance to Cryptography)

### 「添一個元素」是體擴張的標準動作

整個體擴張理論的核心操作只有一個：**從 $K$ 出發，丟進一個新元素 $a$，
把所有算得出來的東西收集起來**。

$$K \ \xrightarrow{\ \text{丟進 } a\ } \ K(a)$$

【證明 (b)】說這個收集動作給出的是**最小的**答案 —— 不多不少剛剛好。

這與 [元素的階與循環子群](../Group/Order_of_Element_and_Cyclic_Subgroup.md)
的 $\langle g \rangle$ 是完全平行的想法：
**「由單一元素生成的最小子結構」** 在群、環、體裡各有一個版本。

| 結構 | 記號 | 內容 |
|---|---|---|
| 群 | $\langle g \rangle$ | $g$ 的所有冪次 |
| 環（理想） | $\left\langle a \right\rangle$ | $a$ 的所有倍式 |
| 體 | $K(a)$ | $a$ 的所有有理式 |

### 代數元與超越元：兩種截然不同的結果

【證明 (c)】的註點出了一個關鍵分界：

* **$a$ 是代數元**（滿足某個 $K$-係數多項式方程）$\Rightarrow$ $K[a] = K(a)$，
  而且 $\left[K(a) : K\right] = \deg\left(\text{最小多項式}\right) < \infty$；
* **$a$ 是超越元**（不滿足任何 $K$-係數方程，如 $\pi$ 對 $\mathbf{Q}$）$\Rightarrow$
  $K[a] \subsetneq K(a)$，且 $\left[K(a):K\right] = \infty$。

$\sqrt{2}$ 滿足 $x^2 - 2 = 0$，故是代數元，$\left[\mathbf{Q}\!\left(\sqrt{2}\right) : \mathbf{Q}\right] = 2$
（[塔定理](Tower_Law.md)【證明 (b)】）。

**密碼學只用代數元**，因為超越元沒有有限表示，電腦存不下。

### $GF(2^8)$ 就是一個單擴張

把 [模不可約多項式的商環是體](Quotient_by_Irreducible_is_Field.md) 的結果
翻譯成本檔的語言：

$$GF(2^8) = \mathbf{Z}_2[x]\big/\left\langle m(x) \right\rangle = GF(2)\!\left(\alpha\right), \qquad m(\alpha) = 0$$

其中 $\alpha = \bar{x}$ 是 $m(x) = x^8+x^4+x^3+x+1$ 的一個根。

**AES 的一個位元組，就是 $GF(2)$ 添進 $\alpha$ 之後的一個元素。** 而且由
[模不可約多項式的商環是體](Quotient_by_Irreducible_is_Field.md)【證明 (b)】，
它可以唯一寫成 $\alpha$ 的次數 $< 8$ 的多項式：

$$b_7\alpha^7 + b_6\alpha^6 + \cdots + b_1\alpha + b_0 \qquad \left(b_i \in \left\{0, 1\right\}\right)$$

$\left(b_7, \dots, b_0\right)$ 就是那八個位元。

### 分母有理化 = 求反元素

【證明 (c)】的註揭露了一件實用的事：**分母有理化就是在求乘法反元素**。

$$\frac{1}{c + d\sqrt{2}} = \frac{c - d\sqrt{2}}{c^2 - 2d^2}$$

同樣的技巧在密碼學裡天天用：

* **$GF(p^2)$ 的反元素**（配對密碼學的中間體）：
  $\left(a + b\sqrt{\beta}\right)^{-1} = \dfrac{a - b\sqrt{\beta}}{a^2 - \beta b^2}$，
  一次 $GF(p)$ 的反元素加幾次乘法就搞定，比在 $GF(p^2)$ 裡跑擴展歐幾里得快得多。
* **橢圓曲線的射影座標**：避免除法的做法，本質上是把分母延後到最後一次性有理化。

**「共軛乘法」是有限體實作裡最常見的優化手法之一**，而它的數學內容就是本檔的【推導 1】。

### 程式思維

```python
class Q_sqrt2:
    """Q(√2) 的實作：每個元素存 (p, q) 代表 p + q√2（證明 (c)）。"""
    def __init__(self, p, q):
        self.p, self.q = Fraction(p), Fraction(q)

    def __mul__(self, o):
        # (p1+q1√2)(p2+q2√2) = (p1p2+2q1q2) + (p1q2+q1p2)√2
        return Q_sqrt2(self.p*o.p + 2*self.q*o.q, self.p*o.q + self.q*o.p)

    def inverse(self):
        # 推導 1 + 證明 (c) 的註：共軛除以範數
        norm = self.p**2 - 2*self.q**2
        assert norm != 0, "只有 0 沒有反元素"
        return Q_sqrt2(self.p / norm, -self.q / norm)
```

`inverse` 那三行就是【推導 1】與【證明 (c)】的註 ——
**$\left[\mathbf{Q}\!\left(\sqrt{2}\right):\mathbf{Q}\right] = 2$ 讓每個元素只要兩個座標，
反元素只要一次有理數除法。** 擴張次數越低，實作越便宜，
這是密碼學選參數時的一個實際考量。
